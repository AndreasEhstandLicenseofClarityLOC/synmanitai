# Security Policy

## Scope

This repository contains a static research publication (a founding essay and its accompanying website plus metadata). It has **no backend, no user accounts, no data collection, and no executable services**. As such, the classic attack surface is minimal.

## Reporting a vulnerability or concern

If you discover a security issue, a content-integrity problem (e.g. a tampered file or an injected link), or a privacy concern, please report it responsibly:

- **Email:** ehstand.schule@gmail.com
- Please include a clear description, the affected file or URL, and steps to reproduce if applicable.

We ask that you:
- Give us a reasonable opportunity to address the issue before any public disclosure.
- Avoid privacy violations, data destruction, or service disruption while investigating.

## Response

- Acknowledgement target: within a reasonable time after receipt.
- We will investigate, confirm, and remediate confirmed issues, and keep you informed of progress.

## Out of scope

- Reports about the absence of a backend, login, or cookies (by design there is none).
- Best-practice suggestions for the static-hosting provider (GitHub Pages) — please direct those to the provider.
