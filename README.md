# synmanitai

Synmanitai — a descriptive concept-name for the cultural form of shared thinking between humans and language models. Part of the open MANITAI Research Programme. CC BY-NC-ND 4.0.

**Live:** https://andreasehstandlicenseofclarityloc.github.io/synmanitai/

## What is Synmanitai?

A name for the cultural pattern that emerges when a human and a language model engage in sustained, exploratory dialogue: not the human alone, not the model alone, but the form of thinking that takes shape between them. Synmanitai is descriptive — it does not normalize, recommend, or evaluate AI use. It only names what is observed.
